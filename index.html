Installation Guide

วิธีลงม็อดใน CurseForge App (ง่ายใน 3 ขั้นตอน)

ไม่ต้องลากไฟล์เอง ไม่ต้องลงทีละม็อด โหลดปุ๊บ Import ปั๊บเข้าเล่นได้ทันที

01
Step 1

โหลดไฟล์ .zip

กดปุ่ม ดาวน์โหลดม็อดแพ็ก ด้านบนเพื่อเซฟไฟล์ KUY RAI I KAK-2.0.0.zip ลงในคอมพิวเตอร์ของคุณ (ไม่ต้องแตกไฟล์ zip ออกมา)

02
Step 2

กด Import ใน CurseForge

เปิดโปรแกรม CurseForge App ไปที่แถบ Minecraft แล้วกด Create Custom Profile จากนั้นเลือกเมนู Import แล้วเลือกไฟล์ .zip ที่เพิ่งโหลดมา

03
Step 3

กด Play แล้วลุยเลย!

รอ CurseForge ดาวน์โหลดม็อดสักครู่จนครบ 100% จากนั้นกดปุ่ม Play เพื่อเข้าเกม ใส่ IP เซิร์ฟเวอร์ แล้วชวนเพื่อนมาสร้างโรงงานด้วยกันได้เลย!

Latest Release

บันทึกการอัปเดต v2.0.0

Current Version
  • แก้ปัญหาเควสขึ้น "Unnamed": อัปเดตโครงสร้างภาษาภาษาไทยและภาษาอังกฤษของ FTB Quests ให้แสดงผลชื่อหมวดหมู่และคำอธิบายเควสครบถ้วน
  • เพิ่มม็อดตัดไม้ (FallingTree): ตัดโคนไม้ครั้งเดียวไม้ล้มทั้งต้น ประหยัดเวลาสร้างบ้าน
  • ปรับแต่งประสิทธิภาพ Sodium 0.8: เคลียร์ม็อดที่ไม่เข้ากันออก ทำให้รัน Shader ได้ลื่นไหล FPS นิ่งขึ้น
  • ซิงก์ตรงกับ Dedicated Server: ปรับแต่งการตั้งค่าเน็ตเวิร์กให้ตรงกับเซิร์ฟเวอร์ เข้าเล่นแล้วไม่หลุด
